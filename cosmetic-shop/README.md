# Cosmetic Shop Management System

Desktop app (Electron) for managing a cosmetic and artificial jewelry shop.
Offline-first, SQLite-backed, PKR currency, no tax.

## Stack
- Backend: Node.js + Express + Prisma + SQLite
- Frontend: React + Vite
- Desktop: Electron

## Dev
    pnpm install
    pnpm db:generate
    pnpm db:migrate
    pnpm db:seed
    pnpm dev
